# Google Drive 원문 등록 확인

원본 폴더: [은혜로120 송재현/원문](https://drive.google.com/drive/folders/171SGtBwV2b_QN4x-tfOShEo4qgAWJg04)

사용자가 공개 GitHub 업로드를 명시적으로 승인한 후 등록했습니다. Drive 파일은 이동·수정하지 않고 복사했습니다. 인코딩이나 줄바꿈을 바꾸지 않고 원본 바이트 그대로 등록했습니다. Git blob 해시는 `SHA-1("blob " + 바이트수 + NUL + 원본바이트)`로 계산하여 GitHub의 반환값 및 브랜치의 파일 해시와 비교했습니다.
