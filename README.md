# grace120 — 은혜로120 말씀정리

송재현 말씀 자료를 소스 → 설교요약 → 마스터 순서로 정리하는 작업 공간입니다.

| 공간 | 용도 |
| --- | --- |
| [소스](소스/) | 영상 링크, 녹취록, 원문 메모 |
| [설교요약](설교요약/) | 성경 본문, 핵심 메시지, 적용 정리 |
| [마스터](마스터/) | 검토를 마친 최종 정리본과 전체 목록 |

## 사용 순서

1. 소스/양식.md를 복사하여 출처와 원문을 기록합니다.
2. 설교요약/양식.md를 복사하고 해당 소스를 연결하여 요약합니다.
3. 검토한 내용을 마스터/양식.md로 정리하고 마스터/목록.md에 추가합니다.

파일 이름은 `YYYY-MM-DD_설교제목.md`로 통일합니다. 날짜를 모르면 `날짜미상_설교제목.md`를 사용합니다. 동일한 설교의 파일은 세 폴더에서 같은 이름을 사용합니다.

Google Drive 원문 6개를 소스 폴더에 등록했고, 「일곱 날의 창조」의 8편 요약과 별도 검증 기록을 작성했습니다. [전체 현황](INDEX.md)에서 확인할 수 있습니다.

양식의 빈칸은 확인된 자료로 채워 주세요. 직접 인용과 요약자의 해석을 구분하고, 확인하지 못한 내용은 확인 필요로 표시합니다.

## 작업 공간 열기

VS Code에서 grace120.code-workspace 파일을 엽니다.

## 현재 작업 기준

설교별 새 요약본은 사용자 작업지시서 v2.0에 따라 성경 원문·의역·핵심 공식·설교 본문으로 작성합니다. 기존 날짜형 양식보다 [현재 작업 기준](작업기준_v2.0.md)을 우선합니다. 마스터는 이번 작업에서 생성하거나 수정하지 않습니다.
